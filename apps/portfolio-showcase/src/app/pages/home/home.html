FAQ

How many libraries are here right now? +

Five so far, Data Grid, Form Builder, Auth, PDF Generator, and Calendar. This site is built to host a growing set of them, new ones show up in the Library Explorer above as they're finished, not bundled into this one.

Is this free to use? +

Yes, every library in this ecosystem ships under the MIT license, free for any use. Some may add optional paid Pro tiers for specific advanced features down the line, but there's no fixed timeline for that yet.

What Angular versions are supported? +

Every library here targets the same floor: ^20.0.0 || ^21.0.0 || ^22.0.0, reviewed each time Angular ships a new major.

Why build these instead of using something like Angular Material? +

Complete design systems are excellent, but they require adopting their entire visual language and CDK just to obtain a single component. Each library presented here focuses on a single problem, has no dependencies on CSS frameworks, and is small in size. They don't replace a complete design system when you really need one, but rather serve as an alternative when you don't.
