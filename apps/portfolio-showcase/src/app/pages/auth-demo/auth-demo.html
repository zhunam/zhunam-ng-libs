@zhunam/auth

Live Demo

A thin, unified wrapper over Firebase Auth and Supabase Auth — reactive user state, a route guard, and ready-made login/register/reset-password forms. This demo runs against an in-memory mock, never a real Firebase or Supabase project.

Behavior is identical — switching providers doesn't require touching your application code, only the entry point you import from and provide in app.config.ts (see Usage below).
